# 🌸 Ramalhete de Lírios Rosa 3D

Site com um ramalhete de lírios rosa (estilo Stargazer) renderizado em 3D com [Three.js](https://threejs.org/).

- Ramalhete suspenso no ar, centralizado na página
- Rotação 360° — arraste com o mouse (ou o dedo, no celular) para girar
- Rotação automática suave e flutuação no ar
- Pétalas geradas proceduralmente, com pintas, faixa central e bordas brancas características do lírio
- 5 flores abertas, 3 botões, folhas, caules e laço de fita

## Como rodar

Basta abrir o `index.html` em um navegador (precisa de internet para carregar o Three.js via CDN), ou servir localmente:

```bash
cd lirio-3d
python3 -m http.server 8000
# abra http://localhost:8000
```
